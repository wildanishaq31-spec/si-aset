## 🎯 Aturan Inti Proyek (Core Principles)
1. **Preservasi Fitur & Layout GAS**: Seluruh layout kartu, penempatan section, tabel, dan fitur operasional dari `Index_GAS.html` dipertahankan 100%.
2. **Modern React + Vite Theme**: Menggunakan styling CSS modern, komponen responsif, transisi halus, dan typography yang jernih.
3. **Ikon Menarik & Berwarna**: Menggunakan set ikon emoji/3D modern yang atraktif pada setiap menu dan kartu ringkasan.
4. **Sinkronisasi Otomatis**: Setiap diskusi, keputusan desain, dan fitur baru dicatat secara terstruktur ke dalam Obsidian Vault ini.
